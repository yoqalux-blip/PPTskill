# Legacy Routes Archive

This folder stores historical route files that are no longer part of the locked production workflow.

Do not execute anything in this folder during normal `paper-to-defense-ppt` production runs. These files exist only for historical reference or explicit legacy experiments requested by the user.

Archived here are experiments such as:

- draw.io route reconstruction
- Gemini hybrid page assembly
- native-PPT diagram routes
- visual QA repair loops
- Figma and Canva oriented support documents
- early template placeholders that are not part of the current `cdutcm-defense` mainline
- archived image-to-PPTX packaging and PowerPoint normalization helpers

The current production workflow is documented in:

- `../../SKILL.md`
- `../../references/current-skill-package.md`
